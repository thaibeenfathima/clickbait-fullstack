## 🚀 How to Run (Quick Reference)

### 1. Install Backend Dependencies (One-time)
```bash
pip install -r requirements.txt
```

### 2. Start Backend (Terminal 1)
```bash
python api_server.py
# http://localhost:5000
```

### 3. Start Frontend (Terminal 2)
```bash
cd frontend
npm run dev
# http://localhost:5173
```

### 4. Open Browser
```
http://localhost:5173
```

**Total setup time: < 5 minutes** ⏱️
